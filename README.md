# GoMontagPublic
Public Repository for the GoMontag Website Application Project

## Website Link
[www.gomontag.com](https://www.gomontag.com)

## Description
A custom wiki website, where users can look up different products by their title, creator, and product category. Users can get information provided about information regarding:
* Whether or not a potential buyer owns that product based on the format/version
* What parts of a product/format are tied to an online service
* Major differences between different the current format/version and previous versions
